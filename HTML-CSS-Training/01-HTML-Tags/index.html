HTML Tags

HTML Tags are the building blocks of HTML documents. With HTML tags, you can create a simple web page.

🧱 Block-Level vs. Inline Elements

Block-Level Elements

These elements start on a new line and take up the full width of the page.

  • div
  • header
  • main
  • footer

Inline Elements

These elements only take up the width of the content they contain.

  1. span
  2. em
  3. strong

🏷️ Structural & Semantic Elements

These tags tell search engines and browsers exactly what kind of content sits inside them, which heavily boosts SEO and digital accessibility.

  • Header & Footer

    • Defines the top and bottom navigation or informational zones.

  • Nav

    • Specifically wraps primary website navigation links.

  • Article & Section

    • Segments independent blog posts or logical content chapters.

📥 Form & Interactive Elements

Used to gather user input and data from the user and send it to a server for processing or saving data in a database.
